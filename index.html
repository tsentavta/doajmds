Синтаксис запросов
Поиск по полю: bibjson.title:"wave propagation" · сокращения: doi: issn: title: license:CC-BY
Логика: AND, OR, NOT, скобки · диапазон: bibjson.year:[2020 TO 2023]
Наличие поля: _exists_:bibjson.abstract, отсутствие: NOT _exists_:bibjson.author.orcid_id
Статьи без DOI: NOT _exists_:index.doi или NOT bibjson.identifier.type:doi — сокращение doi: работает только для поиска по значению, поля doi в индексе нет
DOI со слешем заключайте в кавычки: doi:"10.18469/1810-3189.2022.25.4.122-128"
Точное совпадение всего значения: суффикс .exact — bibjson.journal.title.exact:"Journal of Science" (только для полей с полным именем, не для сокращений)
Значения: логические поля bibjson.* — true/false; флаги index.* — Yes/No; index.country и index.language — английские названия ("Russian Federation", Russian), а bibjson.*.country/language — коды (RU)
Диапазоны только закрытые: created_date:[2026-01-01 TO 2026-06-30]; TO * запрещено. Все записи: запрос *
Шаблоны * и ? внутри слов, нечёткий поиск ~ и регулярные выражения DOAJ не разрешает. По одному запросу доступны только первые 1000 результатов.

    API-ключ DOAJ
    
    
    Нужен для создания, изменения и удаления статей. Ключ берётся в личном кабинете DOAJ: Dashboard → Settings → «Generate a new API key». Поиск и экспорт работают без ключа.
    
    
    
      
      
      
    
    
    
    
    Без галочки ключ хранится только до закрытия вкладки. Ключ отправляется только на doaj.org.
    
    
    
  
    
  
    
    
    Работа с API
    
    
    
    DOAJ ограничивает частоту запросов (около 2 в секунду). При ответе 429 приложение повторяет запрос автоматически.
    
    
    Тема
    
    
    
  
    

    


    
  
    DOAJ Metadata Studio — работа с метаданными статей в DOAJ
    
  
    Бесплатный онлайн-инструмент для редакторов и издателей научных журналов открытого доступа. Позволяет искать статьи и журналы в DOAJ (Directory of Open Access Journals), загружать и исправлять статьи через DOAJ API, проверять полноту метаданных и выгружать данные в Excel — прямо в браузере, без установки и регистрации.
    
  
    
    
    
      
    Поиск по всем полям DOAJ
    
      
    Конструктор запросов по 54 полям статей и 83 полям журналов: название, авторы, ORCID, DOI, ISSN, год, том, выпуск, лицензия, издатель. Встроенный справочник полей с примерами помогает составить запрос без изучения документации API.
    
    
    
    
    
      
    Загрузка и редактирование статей
    
      
    Форма для создания и исправления статьи в DOAJ с проверкой при вводе: контрольные цифры ISSN и ORCID, формат DOI, ссылка на полный текст, число ключевых слов. Массовая загрузка выпуска из CSV или Excel.
    
    
    
    
    
      
    Проверка метаданных журнала
    
      
    Выгрузка всех статей журнала по ISSN и отчёт о проблемах: статьи без DOI, дубли, пропущенные аннотации, ключевые слова, аффилиации и ORCID авторов. Сверка со списком DOI из Crossref или с сайта журнала.
    
    
    
    
    
      
    Экспорт в Excel и JSON
    
      
    Выгрузка в CSV, совместимый с массовой загрузкой: исправьте данные в Excel и загрузите обратно. Ограничение DOAJ API в 1000 записей обходится автоматически.
    
    
    
  
    
  
    Как начать
    
  
      
    
    1. Чтобы найти статьи журнала, выберите на вкладке «Поиск» поле «ISSN журнала» и введите ISSN.
      2. 
    
    2. Чтобы проверить метаданные всего журнала, откройте вкладку «Экспорт и сверка» и загрузите статьи по ISSN.
      3. 
    
    3. Чтобы загружать и исправлять статьи, получите API-ключ в личном кабинете DOAJ (Dashboard → Settings) и введите его во вкладке «Настройки».
      4. 
  
    
  
    Частые вопросы
    
  
    
    
    Это официальный сервис DOAJ?
    
    
    Нет. Это независимый инструмент с открытым исходным кодом, который работает с публичным DOAJ API v4.
    
    
    Куда отправляется мой API-ключ?
    
    
    Только на doaj.org. Приложение работает целиком в браузере, своего сервера у него нет. По умолчанию ключ хранится до закрытия вкладки.
    
    
    Как найти статьи журнала без DOI?
    
    
    Запрос issn:1234-5678 AND NOT _exists_:index.doi на вкладке «Поиск» или карточка «Без DOI» на вкладке «Экспорт и сверка».
    
    
    Сколько это стоит?
    
    
    Бесплатно. Код открыт под лицензией MIT на GitHub.
