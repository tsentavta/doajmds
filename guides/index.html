Инструкции по работе с DOAJ

Практические инструкции для редакторов и издателей журналов открытого доступа. Каждая инструкция проверена на живом DOAJ API и ведёт в DOAJ Metadata Studio — бесплатный инструмент, где описанное можно сделать в пару кликов.

  • Как загрузить статьи в DOAJ: вручную, XML, CSV и API

    Четыре способа загрузить метаданные статей в DOAJ: форма на сайте, XML (DOAJ и Crossref), CSV через API и DOAJ API. Требования, дубли и частые ошибки.

  • Массовая загрузка статей в DOAJ из Excel и CSV

    Как загрузить выпуск журнала в DOAJ из таблицы Excel: шаблон CSV, формат авторов и ключевых слов, проверка перед отправкой, пакеты по 600 КБ и статус загрузки.

  • Как найти статьи без DOI, ORCID и аннотаций в DOAJ

    Готовые запросы DOAJ API для поиска статей журнала без DOI, ORCID, аннотаций и ключевых слов, проверка всего журнала одной кнопкой и исправление найденного.

  • Как выгрузить все статьи журнала из DOAJ

    Как скачать все статьи журнала из DOAJ в Excel (CSV) или JSON, обойти ограничение DOAJ API в 1000 записей и когда нужна полная выгрузка данных DOAJ.

  • Поиск в DOAJ API: синтаксис запросов и поля

    Синтаксис поиска DOAJ API v4: поля статей и журналов, сокращения, .exact, диапазоны, _exists_, сортировка, лимиты и неочевидные ловушки — с проверенными примерами.
