You need the list of a journal’s DOAJ articles to reconcile it with the website, report on it or fix metadata. The DOAJ website has no “download all articles of this journal” button, and the DOAJ API returns at most 1000 records per query. Here is how to get everything.

The quick way: the “Export & audit” tab

  1. Open the “Export & audit” tab and enter the journal ISSN — print or online.
  2. Click “Load”. Progress and a request log appear below the field.
  3. Choose an export format:
    • CSV — for Excel; you can choose the delimiter. The file round-trips with bulk upload: fix the data and upload it back.
    • JSON (full records) — everything DOAJ stores about the articles, including system fields.
    • JSON for re-upload — just the article metadata, in the format the DOAJ API accepts.
    • ID list and DOI list — one per line.

No API key is needed: the export uses public data. You also get a summary of metadata problems: articles without DOI, duplicates, missing abstracts, ORCIDs and affiliations.

The 1000-record limit and how to get around it

The DOAJ API returns results in pages of 100, but never beyond the thousandth: asking for page 11 returns “You cannot access results beyond 1000 records via this API”. Large journals have more articles than that.

The workaround is simple: split one query into several, each matching fewer than 1000 articles. DOAJ Metadata Studio does this automatically — it halves the query by the DOAJ record creation date (created_date) until every part is under 1000, then merges the results and drops repeats. The same trick works by hand:

issn:1234-5678 AND created_date:[2018-01-01 TO 2022-01-01}
issn:1234-5678 AND created_date:[2022-01-01 TO 2026-12-31]

The curly brace } excludes the upper bound, so no article lands in both parts. DOAJ rejects open ranges like TO *, so give the upper bound as a date.

The only case where splitting does not help: more than 1000 records created in DOAJ in the same second (one big upload). The app then warns that only the first thousand of that part is available.

Exporting by query instead of by journal

Switch the mode to “By query” and enter any DOAJ API query — for example, all of a publisher’s articles, or articles on a topic over several years:

bibjson.journal.publisher:"Samara" AND bibjson.year:[2023 TO 2024]

Query syntax is covered in DOAJ API search: query syntax and fields.

When you need the full DOAJ data dump

If you need all of DOAJ rather than one journal — hundreds of thousands of journals and millions of articles — the API is the wrong tool. DOAJ provides full data dumps on request: access is granted case by case, and you write to the platform manager explaining who you are and what the data is for. The journal list in CSV format can be downloaded straight away, without a request.
