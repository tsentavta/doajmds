Query syntax
Search a field: bibjson.title:"wave propagation" · short names: doi: issn: title: license:CC-BY
Logic: AND, OR, NOT, parentheses · range: bibjson.year:[2020 TO 2023]
Field present: _exists_:bibjson.abstract, missing: NOT _exists_:bibjson.author.orcid_id
Articles without DOI: NOT _exists_:index.doi or NOT bibjson.identifier.type:doi — the short name doi: only works when searching by value; the index has no doi field
Quote DOIs that contain a slash: doi:"10.18469/1810-3189.2022.25.4.122-128"
Exact match of the whole value: suffix .exact — bibjson.journal.title.exact:"Journal of Science" (full field names only, not short names)
Values: boolean fields bibjson.* — true/false; flags index.* — Yes/No; index.country and index.language — English names ("Russian Federation", Russian), while bibjson.*.country/language — codes (RU)
Ranges must be closed: created_date:[2026-01-01 TO 2026-06-30]; TO * is not allowed. All records: query *
Wildcards * and ? inside words, fuzzy search ~ and regular expressions are not allowed by DOAJ. Only the first 1000 results of a query are available.

    DOAJ Metadata Studio — work with DOAJ article metadata
    
  
    A free online tool for editors and publishers of open access scholarly journals. Search articles and journals in DOAJ (Directory of Open Access Journals), upload and fix articles via the DOAJ API, audit metadata completeness and export data to Excel — right in the browser, with nothing to install and no sign-up.
    
  
    
    
    
      
    Search by any DOAJ field
    
      
    A query builder covering 54 article fields and 83 journal fields: title, authors, ORCID, DOI, ISSN, year, volume, issue, license, publisher. A built-in field reference with examples helps you write a query without studying the API docs.
    
    
    
    
    
      
    Upload and edit articles
    
      
    A form for creating and fixing an article in DOAJ with live validation: ISSN and ORCID check digits, DOI format, full-text link, number of keywords. Bulk upload of a whole issue from CSV or Excel.
    
    
    
    
    
      
    Journal metadata audit
    
      
    Export every article of a journal by ISSN and get a problem report: articles without DOI, duplicates, missing abstracts, keywords, author affiliations and ORCID iDs. Reconcile against a DOI list from Crossref or the journal website.
    
    
    
    
    
      
    Export to Excel and JSON
    
      
    Export to CSV that round-trips with bulk upload: fix the data in Excel and upload it back. The DOAJ API limit of 1000 records is worked around automatically.

    FAQ
    
  
    
    
    Is this an official DOAJ service?
    
    
    No. It is an independent open source tool that works with the public DOAJ API v4.
    
    
    Where is my API key sent?
    
    
    Only to doaj.org. The app runs entirely in your browser and has no server of its own. By default the key is kept until the tab is closed.
    
    
    How do I find a journal’s articles without a DOI?
    
    
    Use the query issn:1234-5678 AND NOT _exists_:index.doi on the “Search” tab, or the “No DOI” card on the “Export & audit” tab.
    
    
    How much does it cost?
    
    
    Nothing. The code is open source under the MIT license on GitHub.
